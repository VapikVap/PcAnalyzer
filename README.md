# PC Performance Analyzer

Windows-приложение, которое записывает состояние ПК во время игр, само находит просадки и фризы и объясняет простым языком, что ограничивало производительность и что с этим сделать. Все данные хранятся локально, анализ работает без интернета.

## Запуск

Требуется .NET SDK 8+ (собирается и SDK 10), Windows 10 2004+ / Windows 11.

```powershell
dotnet build PcAnalyzer.sln -c Release
```

```powershell
.\src\PcAnalyzer.App\bin\Release\net8.0-windows\PcAnalyzer.exe
```

```powershell
dotnet test
```

### Установщик

Нужен Inno Setup 6 (`winget install JRSoftware.InnoSetup`).

```powershell
powershell -ExecutionPolicy Bypass -File .\build-installer.ps1
```

Результат: `artifacts\PcAnalyzer-Setup-<версия>.exe`. Это самодостаточная сборка: на целевом ПК .NET не нужен. В неё входят PresentMon (`<папка приложения>\PresentMon`, используется, если в настройках путь не указан), ярлыки в «Пуске» и на рабочем столе, а также опциональный автозапуск. Удаляется через «Приложения» Windows, история и настройки в `%LOCALAPPDATA%\PcAnalyzer` при этом сохраняются. Повторный запуск ярлыка при работающем приложении открывает его окно.

### Обновления

При запуске (и затем раз в 6 часов) приложение проверяет последний релиз на [GitHub](https://github.com/VapikVap/PcAnalyzer/releases). Если версия новее, в боковой панели появляется кнопка «Обновить». Приложение скачивает `PcAnalyzer-Setup-*.exe`, проверяет SHA-256 и запускает установщик с ключом `/UPDATE`. Установщик ждёт закрытия приложения (активная сессия при этом сохраняется), ставит новую версию без вопросов и запускает её.

Как выпустить новую версию:

1. Поднять `<Version>` в `Directory.Build.props`, например до `0.2.0`, и закоммитить.
2. Отправить тег:

```powershell
git tag v0.2.0
```

```powershell
git push origin main v0.2.0
```

После этого GitHub Actions (`.github/workflows/release.yml`) прогонит тесты, соберёт установщик и опубликует релиз.

Аргументы: `--minimized` (старт в трей, используется автозапуском), `--page=History` (открыть страницу).

## Оптимизация

Страница «Оптимизация» проверяет настройки Windows, которые влияют на игры: план электропитания, игровой режим, фоновую запись Xbox Game Bar, свободное место на дисках, файл подкачки, возраст драйвера видеокарты, автозагрузку и аппаратное планирование GPU. То, что безопасно менять без прав администратора (план питания, игровой режим, фоновая запись), исправляется кнопкой. Исходное значение сохраняется в `%LOCALAPPDATA%\PcAnalyzer\tweaks-backup.json`, и кнопка «Вернуть» его восстанавливает. Для остального есть кнопка, которая открывает нужный раздел Windows.

В разборе сессии у находок есть кнопки действий: закрыть фоновые программы из отчёта, освободить память, переключить план питания, открыть автозагрузку или очистку диска. Перед закрытием программ приложение спрашивает подтверждение. Системные процессы и антивирус не трогаются (`ProcessCloser`).

## Что даёт запуск от администратора

Без прав администратора работает всё, кроме температуры/мощности CPU (LibreHardwareMonitor + драйвер PawnIO) и записи FPS через PresentMon. Кнопка «Перезапустить от администратора» есть на странице сессии и в настройках.

## FPS и время кадра

В установщике PresentMon уже есть. При запуске из исходников:

1. Скачайте консольную версию PresentMon с https://github.com/GameTechDev/PresentMon/releases (лицензия MIT).
2. Настройки → «Источник FPS» → укажите путь к exe → «Сохранить».
3. Запустите приложение от администратора (или добавьте пользователя в группу «Пользователи журналов производительности»).

Без PresentMon FPS не показывается и не подменяется — отчёт строится по загрузке и сенсорам, а ограничение указывается в разделе «Ограничения данных».
